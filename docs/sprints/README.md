# Sprint worklogs

Keep one folder per sprint, named `sprint-NN`, with its `worklog.md`. Add one short entry whenever you spend time working on the application. Times use India Standard Time.

## Daily entry

Write the date, start and end time, duration, and the L4 tasks or other work you completed or progressed.

Example format only, to replace with your own session details.

- November 22, 2026 · 10–11 AM · 1 hour · GT-05 — completed GT-05.02 frontend setup and worked on GT-05.03 backend setup.

An entry can cover several tasks in the same L3. If a session covers multiple L3s, include a rough time split so the weekend totals can be calculated. For example, 40 minutes on GT-05 and 20 minutes on GT-01.

## Weekend review

At the weekend, add up the session time for each L3 and record the cumulative total in the [first-release plan](../first-release-plan.md). Include time from earlier sprints when the same L3 spans several sprints. Compare a completed L3's total with its original estimate. For an ongoing L3, record time spent so far and adjust the remaining forecast if needed.

Use the logged time as the source for actual hours. Earlier work can be added when you remember its duration. The release baseline starts on November 22, so keep earlier time separate when comparing with that remaining-effort estimate.
