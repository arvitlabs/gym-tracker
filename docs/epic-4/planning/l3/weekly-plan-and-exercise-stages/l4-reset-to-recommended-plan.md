# L4 — Reset to the recommended plan

**ID** GT-03.05\
**Parent** [L3 — Weekly plan and exercise stages](l3-weekly-plan-and-exercise-stages.md)\
**Board issue type** Task

**Scope** Replace the active plan with a recommended copy online. Archive the prior plan and retain activation timing, workout references, and user exercise progression.

**Depends on** [Versioned plan templates](../onboarding-and-first-plan/l4-seed-plan-templates.md) and one-active-plan enforcement.

## Acceptance criteria

- Given the user customized their plan, when they reset it online, then the recommended copy becomes active, the old plan is archived, and workout history and progression remain available.
- Given two replacement requests overlap, when they complete, then the user has exactly one active plan and activation history is preserved.
