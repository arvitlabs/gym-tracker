# L4 — Reorder exercises within a section

**ID** GT-03.04\
**Parent** [L3 — Weekly plan and exercise stages](l3-weekly-plan-and-exercise-stages.md)\
**Board issue type** Task

**Scope** Save a changed order online within one section. Keep exercise identities and completed targets intact when updating an active workout.

**Depends on** [Active plan week](l4-show-active-plan-week.md) and workout draft integration for edits during a session.

## Acceptance criteria

- Given the user reorders exercises in a section online, when they reopen the plan, then the new order persists within that section.
- Given an affected workout is active, when the order changes online, then the active workout reflects the order and preserves completed sets and their original targets.
