# L4 — Add the next exercise stage

**ID** GT-03.08\
**Parent** [L3 — Weekly plan and exercise stages](l3-weekly-plan-and-exercise-stages.md)\
**Board issue type** Task

**Scope** Append an editable stage based on the last one without changing the current stage. Confirm the increment rule before implementing the suggested harder target.

**Depends on** [Exercise stages](l4-show-exercise-stages.md) and the rule for the suggested increment.

## Acceptance criteria

- Given an exercise has a last stage, when the user adds the next stage online, then one stage is appended using the agreed increment and the current stage selection is preserved.
