# L4 — Show the generated plan

**ID** GT-02.07\
**Parent** [L3 — Onboarding and first plan](l3-onboarding-and-first-plan.md)\
**Board issue type** Task

**Scope** Render the generated week with day focus and exercise counts. Link Looks good to Today and Reorder to Plan · Week.

**Depends on** [Plan generation](l4-generate-first-plan.md) and destinations for Today and Plan · Week. Destination features are tracked under their own Epics.

## Acceptance criteria

- Given a four- or five-day plan is saved, when Plan Result opens, then it shows the generated days, focus, and exercise counts.
- Given the result is visible, when the user selects Looks good or Reorder, then the matching destination opens.
