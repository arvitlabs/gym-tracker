## How to read this plan

- Every exercise row has a **Show** column:
  - **Always:** every user on this plan gets it.
  - **FLAG name:** shown only if the user selected that posture concern at onboarding.
- **Posture flags** (onboarding question "Posture concerns?"):

| Flag | Onboarding option |
|---|---|
| `FORWARD_HEAD` | Forward head |
| `ROUNDED_SHOULDERS` | Rounded shoulders |
| `LOWER_BACK_ARCH` | Lower-back arch |
| *(none)* | Not sure / none: user sees only the "Always" rows |

- **Multiple flags:** show every matching row. If the same exercise appears twice for one day, show it once.

## Plan rules (beginner)

| Rule | Value |
|---|---|
| Weeks 1–2 (ease in) | **2 sets** per gym exercise, stop with 3–4 reps left |
| Week 3 onward | Full sets as listed, stop with **2–3 reps left** |
| Tempo | Lift with control, lower in 2–3 s |
| Progression | When **every set** hits the top of the rep range, add the smallest weight step next session |
| Ramp-up sets | Before the first exercise: light ×10, then medium ×5 |
| Form | When form breaks, the set ends; joint pain → change the angle or the exercise |

Warm-up and cool-down items don't use sets × reps progression. Just do the listed dose.
